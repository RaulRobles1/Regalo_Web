✏️ Editor de tu regalo

Cambia textos, fotos, vales, quiz… sin tocar código. Al guardar se crea js/config.local.js y se copian las fotos a assets/fotos/.

  1. 1. Pulsa 📁 Elegir carpeta y selecciona la carpeta de este proyecto (solo Chrome/Edge en ordenador).
  2. 2. Edita lo que quieras y pulsa 💾 Guardar.
  3. 3. Abre index.html para ver el resultado, y sube los cambios con git cuando estés listo.

¿Otro navegador o el móvil? Usa ⬇️ Descargar archivos y pon config.local.js en js/ y las fotos en assets/fotos/.
